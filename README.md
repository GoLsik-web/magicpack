# Magic Pack — сайт сервера

Статическая страница сервера Minecraft 1.21.1 (NeoForge). Один файл `index.html`, без сборки.
Публикуется через GitHub Pages.

## Что поправить руками

- **Ссылка на скачивание сборки** — кнопка «Скачать сборку» ведёт на `releases/latest`.
  Залей туда `MagicPack-1.21.1-client.zip` (Releases → Draft a new release → приложить файл).
- **Кнопка «Поддержать сервер»** сейчас ведёт в Discord. Когда появится приём платежей
  (Boosty, DonationAlerts, CloudTips), замени `href` у ссылки с `id="donate"`.
- **Адрес сервера** указан в двух местах: карточка в шапке и шаг 3 в разделе «Как зайти».

## Локальный просмотр

Открыть `index.html` в браузере. Ничего собирать не нужно.
